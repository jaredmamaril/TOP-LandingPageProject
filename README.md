# UIC-Inspired Landing Page

## Overview

This is my version of The Odin Project's Landing Page project. I created a UIC-inspired webpage using HTML and CSS to practice front-end web development.

The page features a UIC-themed design with a navigation bar, welcome message, and a two-column layout.

## Development Process

I used HTML to structure the webpage and CSS to style its appearance.

I designed the page with a UIC logo, red navigation buttons for Life at UIC, Admissions, and Academics, and a welcome section with a Learn More button.

The layout includes a text section on the left and an image placeholder on the right.

**Technologies Used:**
- HTML
- CSS

## What I Learned

This project gave me hands-on practice with structuring webpages using HTML and styling them with CSS.

I also practiced organizing page elements into sections, working with colors and spacing, and building a layout inspired by an existing university website.
